# フォルダ最適化 (Smartphone Folder Optimization)

スマートフォンのストレージ容量を空けるための Android アプリです。

## 機能

- **ストレージ使用量ビューア**: 端末内のディレクトリを容量の大きい順に一覧表示し、フォルダをタップしてドリルダウンしながらファイル単位のサイズも確認できます。
- **重複ファイル検出**: ファイル名とサイズが一致するファイルを重複候補として検出し、グループごとに節約可能な容量を表示します。削除するファイルを選択して一括削除できます（既定では各グループの最新ファイルを残す提案付き）。

## 動作要件

- Android 8.0 (API 26) 以降
- 初回起動時に「すべてのファイルへのアクセス」権限（`MANAGE_EXTERNAL_STORAGE`、Android 11+）または通常のストレージ権限（Android 10 以下）の許可が必要です。

## ビルド方法

本リポジトリは Gradle Wrapper を同梱していません。以下のいずれかでビルドしてください。

```bash
gradle assembleDebug   # Gradle 8.9 以上がインストール済みの環境
```

またはローカルで一度だけ `gradle wrapper --gradle-version 8.9` を実行して wrapper を生成すれば、以降は `./gradlew` も使用できます。Android Studio で本プロジェクトを開いて実行することもできます。

## リリースの仕組み

`main` ブランチにマージされるたびに GitHub Actions (`.github/workflows/release.yml`) が自動的に:

1. `github.run_number` を元にバージョンを採番
2. 署名付きリリース APK (`assembleRelease`) をビルド
3. GitHub Releases に新しいタグとともに APK を公開（リリースノートは自動生成）

します。[Releases ページ](../../releases) から最新の APK をダウンロードし、「提供元不明のアプリ」のインストールを許可した上でサイドロードしてください。

また `main` への push・PR では `.github/workflows/ci.yml` が lint・単体テスト・デバッグビルドを実行します。

## 署名鍵について

本アプリは Google Play などのストアには配布せず、個人利用目的で GitHub Releases から直接配布することを前提としています。そのため、リリース署名用の自己署名鍵 (`keystore/release.keystore`) を意図的にリポジトリへ同梱する方針です（`keystore/release.keystore.base64` として base64 テキスト化して保存し、`release.yml` 内でデコードしてから署名に使用します）。これにより GitHub Secrets の設定なしでも常に同じ鍵で署名され、アプリの更新（上書きインストール）に必要な署名の一貫性が保たれます。

Android は APK のインストールに署名を必須としているため「署名なし」という選択肢自体はありませんが、`keystore/keystore.properties` に記載しているパスワードは **秘密情報ではありません**。Android SDK が開発マシンに自動生成するデバッグ用 `debug.keystore` と同じ、公開されているデフォルトパスワード (`android`) をそのまま使用しています。この鍵はストア配布用の秘密鍵ではなく、あくまで「同じ鍵で継続的に署名してアップデートを成立させる」ためだけのものです。

**注記**: このコミット時点では `keystore/` 一式はまだ追加されていません（別途追加予定）。`keystore/` が存在しない状態では `release.yml` の署名ステップは失敗します。

## 既知の制限

- Android 11 以降のプラットフォーム制限により、他アプリの `Android/data` および `Android/obb` 配下はスキャン・削除の対象にできません。
- 重複ファイルの判定は **ファイル名 + サイズ** の一致のみで行っています（ハッシュ照合は行いません）。高速に動作しますが、たまたま同名・同サイズの別内容ファイルを重複と誤検出する可能性があります。削除前に内容を確認してください。
